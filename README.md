# Cross-Platform Matrix Calculator

A sleek, dark-themed, high-performance cross-platform calculator built using Python and the Flet framework. Powered by the Flutter rendering engine under the hood, this application delivers native performance and a fluid UI across Linux, Windows, macOS, Android, and iOS from a single unified codebase.

## 🚀 Features
* **Cross-Platform Deployable:** Runs natively on desktop and mobile platforms.
* **Dual Input System:** Supports both click/tap interactions and native laptop hardware keyboard inputs.
* **Advanced Evaluation Engine:** Dynamic string calculation mapping with robust error handling to prevent runtime crashes.
* **Responsive Layout:** Adaptive column-row grid optimization with custom double-width asset expansion for zero UI overlaps.

## 🛠️ Architecture & Tech Stack
* **Language:** Python 3.12+
* **Core UI Framework:** Flet (Flutter Backend Engine)
* **Design Philosophy:** Coordinates-based concrete alignment mapping for rock-solid cross-platform stability.
